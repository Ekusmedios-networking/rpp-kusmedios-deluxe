RPP Kusmedios Deluxe

Solución definitiva para emisoras de radio online en WordPress. Soporte para múltiples plataformas de streaming, metadatos en vivo, historial interactivo y Progressive Web App.

Descargar en GitHub Ver características

Potencia y control para tu estación

Optimizado para medios digitales, radios en vivo y creadores de contenido.

📻 Autodetección de Streaming

Configuración simple y autocompletado de URLs de transmisión para tus servidores principales.

🎵 Now Playing en Vivo

Extracción dinámica de artista, título y carátula del tema al aire con actualización constante.

📜 Historial de Transmisión

Muestra los últimos temas emitidos para aumentar el tiempo de permanencia y engagement de tu audiencia.

📱 Soporte PWA Nativo

Permite que los radioescuchas instalen tu emisora como app directa en dispositivos móviles y de escritorio.

⚡ REST API & Metaboxes

Endpoints REST personalizables y paneles metabox de administración ligeros y seguros en WordPress.

🌐 Soporte Multilenguaje

Estructura modular compatible con plataformas de localización como POEditor.

Especificaciones Técnicas

Compatibilidad WordPress WordPress 5.8 o superior
Stack Técnico PHP 7.4+, JavaScript nativo, CSS3, REST API
Servidores de Streaming Icecast, Shoutcast, AzuraCast y streams directos (MP3, AAC, HLS)
